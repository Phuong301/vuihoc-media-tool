Privacy Policy

This policy describes the intended data handling of VUIHOC Media Tool.

Data accessed and purpose

The tool uses Google OAuth to access Google Drive file metadata and advertising media needed for authorized operator workflows. Selected files may be downloaded to the operator’s computer and used to prepare advertising assets.

Storage and sharing

The local workflow stores authorization credentials and working files on the operator’s computer. Selected advertising media and derived thumbnails may be transferred to Meta for the requested advertising workflow. Exported results may contain media identifiers.

Google user data

Google user data is intended to be used only to provide the requested media workflow, in accordance with the Google API Services User Data Policy, including applicable Limited Use requirements.

Access and deletion

Operators can revoke Google authorization through their Google Account connections. Local credentials, downloaded files and exports can be removed from the operator’s computer. Media uploaded to Meta is managed separately through Meta.

Contact

For questions about data handling, contact the application operator through the support email displayed on the Google OAuth consent screen.
